| 令牌 | 设计稿 pt | 典型用途 |
| --- | --- | --- |
| `--fs-h1` | 27 | 页面大标题（「许愿墙」「消息」） |

**价格 / 计数 / 时间一律等宽字体** `ui-monospace, Menlo, Consolas, monospace`。

### 1.4 间距与栅格（**最容易做错的地方**）

- 页面左右内边距 **20pt**（`--fs` 层级下的视觉基准）；内容区上边距从**状态栏 47pt**起算。
- 瀑布流：左右各 **14pt**、列间距 **10pt**（首页）/ **12pt**（搜索、详情相似）。
- 卡片内边距 **9~11pt**；卡片之间的间距 **10pt**。
- **会话行高 74pt** 是已验收值（`padding 12pt×2 + 头像 50pt`，见 `src/pages/chat/index.scss` 的 `.chat__conv`），别改。
- 悬浮 TabBar（代码已实现，仅供参照）：左右各 **16pt**、底部 **22pt**、胶囊内边距 `3pt 8pt 4pt`、图标 **24pt**、文字 **10pt**、中间凸起钮 **34pt**。

### 1.5 玻璃材质（谨慎用）

`backdrop-filter` 在 iOS 可用、部分 Android 退化。**规则**：

- 玻璃层**必须同时给一个不透明兜底底色**（如 `rgba(255,255,255,.72)`）；
- **不要在玻璃上直接压正文小字**；
- 只用于：底部悬浮 TabBar、吸顶筛选条、悬浮主按钮、底部操作栏、导航栏圆钮。

## 2. 小程序特有的约束（**必须遵守，否则做出来实现不了**）

### 2.1 导航栏是「自绘」的，不是原生的

`app.json` 设了 `navigationStyle: "custom"` —— **没有原生导航栏**。所以：

- 页面顶部要留出 **状态栏高度 47pt**（显示时间/信号的那一条）；
- 需要返回/分享的页面，**自己在内容上叠加漂浮圆形玻璃钮**（36pt 圆、白 `82%` 底、1px 白描边、`--fg` 图标、轻微投影）；
- 返回钮固定在左上（距左 16pt、距顶 6pt + 状态栏），标题不要做成整条导航栏。

### 2.2 底部 TabBar 已由代码实现，**设计新页面时不要画它**

自定义 TabBar（`custom-tab-bar/`）是全局浮层，5 个 Tab：**首页 / 许愿 / 出物 / 消息 / 我的**。
形态：左右各 16pt、底部 22pt 的**悬浮玻璃胶囊**，五等分，中间「出物」是**凸起的品牌渐变小圆钮**（34pt 圆）。

- 只有这 5 个页面出现 TabBar，其余页面（分类、订单、设置…）**没有** TabBar；
- 没有 TabBar 的页面，底部不要留出 TabBar 的空白，但**底部主操作栏要吸底**（参考详情页的「收藏 / 聊一聊 / 我想要」）。

### 2.3 技术禁区（实现侧做不到的，请别设计）

| 禁止 | 原因 | 替代方案 |
| --- | --- | --- |
| `color-mix()` / `oklch()` | 小程序 WXSS 不支持 | 用 §1.1 的 hex；派生色请在说明里给算式 |
| 内联 `<svg>` / `<path>` | 小程序不能渲染 SVG | 用 §5 的图标库，或纯 CSS 形状 |
| 外部字体加载 | 小程序加载字体成本高、不稳 | 用系统字体（PingFang SC / 系统默认） |
| 复杂 `box-shadow` 多层 + `filter: blur()` | 真机性能差、部分安卓不掉帧但发灰 | 用 §1.1 的三个阴影令牌 |
| 大面积持续动画 | 影响性能 | 只做进入/按压/切换过渡，静态设计稿可不体现 |
| `position: fixed` 修饰页面内滚动区 | 真机行为不一致 | 用吸底布局（页面纵向 flex + 末位元素吸底） |

### 2.4 触控尺寸

所有可点区域**视觉高度 ≥ 44pt**（设计稿数值）。小于这个值时，请在说明里注明"热区补偿"。

## 3. 现有页面的视觉语言（新页面必须连贯）

已实现并验收的 9 个页面，新页面要和它们**像同一个 App**：

| 页面 | 可借鉴的结构 |
| --- | --- |
| 首页 | 冰蓝渐变页头 → 悬浮搜索胶囊 → 分类横滑圆盘 → 两列瀑布流卡片 |
| 许愿墙 | 页头大标题（其中一个字用 `--brand`）→ 筛选胶囊 → WISH 吊牌大卡 → bento 双卡 → 列表 |
| 消息 | 页头 + bento 双卡（一浅一深渐变）→ 筛选胶囊 → 会话列表 |
| 商品详情 | 漂浮导航 → 图集 → 价格区 → 描述 → 卖家卡 → 留言 → 相似推荐 → 吸底操作栏 |
| 搜索 | 吸顶搜索条 → 历史/热门建议面板 ⇄ 结果瀑布流 |
| 出物 | 页头 → 白卡表单（图片位 / 标题 / 描述 / 价格 / 成色）→ 主按钮 |
| 我的 | 个人卡（头像+认证+数据行）→ 列表行 → 功能入口卡 → 页脚版权 |

**通用模式**（新页面尽量复用）：

1. **页头**：`--grad-page` 冰蓝渐变、底边 32pt 圆角、高度 236~252pt（按内容密度选）；
2. **区块标题行**：左标题（`--fs-h3`，600）+ 右等宽小字说明（`--fs-2xs`，`--muted`）；
3. **列表行**：白卡 + `--border` 1px 描边 + 24pt 圆角 + 20pt 内边距，行内左边图标/缩略图、中间两行文字、右对齐数值；
4. **筛选胶囊**：高 34pt、圆角 999、描边 `--border`、选中态**深墨底白字**（`--ink`）；
5. **主按钮**：`--grad-brand` 底 + 白字 600 + 高 48pt + 24pt 圆角；
6. **次按钮**：白底 + `--border` 描边 + `--fg` 字；
7. **空态**：60pt 圆形浅底 + 图标 + 标题（15pt/600）+ 说明（12.5pt）+ 可选行动按钮。

## 8. 三个最容易返工的点（请重点检查）

1. **不要画底部 TabBar**（除首页/许愿/出物/消息/我的之外），也不要画原生导航栏 —— 这两样小程序里由代码控制，画了实现侧会删掉。
2. **单位是 pt（390 宽画布）**，不是 px（750）。实现侧会把 SCSS 数值 ×2 转成 rpx。你按 390 画，代码按 `设计值×2` 写，真机正好 1:1。
3. **触控高度 ≥ 44pt**、**价格/时间用等宽字体**、**列表行高 74pt** —— 这三条是最常被忽略、也最容易导致"看起来对但真机上别扭"的点。
